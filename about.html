Tentang Website

Anime Character Archive adalah website sederhana yang dibuat sebagai latihan penggunaan framework Bootstrap.

Tujuan

Website ini dibuat untuk mempelajari penggunaan Bootstrap dalam membuat halaman web yang responsive, terstruktur, dan memiliki beberapa halaman.

Teknologi

Website ini menggunakan HTML, CSS, dan Bootstrap 5.
